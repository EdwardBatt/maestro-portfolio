# WORKFLOW CLASSIFICATION

Rather than assigning a unique workflow to every deliverable, assign each deliverable to a **Workflow Template**.

### WF-01 — Standard Digital

Brief → Copy/Content → Design → Internal Review → Client Review → Revision → Approval → Final

### WF-02 — Social Content

Brief → Copy → Creative → Internal Review → Client Review → Revision → Final → Scheduling

### WF-03 — Video Production

Brief → Concept → Script → Storyboard → Pre-production → Production → Edit → Sound → Grade → Internal Review → Client Review → Revision → Master → Delivery

### WF-04 — Photography

Brief → Creative Direction → Pre-production → Shoot → Selection → Retouching → Internal Review → Client Review → Final

### WF-05 — Print

Brief → Copy → Design → Internal Review → Client Review → Revision → Final Artwork → Prepress → Proof → Production → Delivery

### WF-06 — Packaging

Brief → Concept → Design → Internal Review → Client Review → Revision → Artwork → Prepress → Proof → Production → Delivery

### WF-07 — Branding

Brief → Research → Strategy → Concept → Creative Development → Internal Review → Client Presentation → Revision → Approval → Brand System → Guidelines → Asset Production

### WF-08 — Campaign

Brief → Strategy → Concept → Key Visual → Internal Review → Client Presentation → Approval → Asset Development → Adaptations → Final → Deployment

### WF-09 — OOH / Environmental

Brief → Concept → Design → Internal Review → Client Approval → Artwork → Production Specification → Production → Proof → Installation → Delivery

### WF-10 — Long-form Physical Production

Brief → Concept → Creative Development → Production Planning → Production → Post-production → Internal Review → Client Review → Final Master → Physical Production → QA → Delivery

# IMPORTANT SYSTEM PRINCIPLE

A user should ideally select:

**Category**
→ **Deliverable**
→ **Channel**
→ **Format**
→ **Quantity**
→ **Due Date**

The system then determines:

**Workflow**
→ **Required stages**
→ **Required approvals**
→ **Required team roles**
→ **Required files**
→ **Production requirements**
→ **Final delivery requirements**

For example:

**Social Media → Reel**

automatically gets:

> Social Content Workflow

while:

**Advertising → Billboard**

gets:

> OOH Workflow

and:

**Print → Brochure**

gets:

> Print Workflow

and:

**Video → TVC**

gets:

> Video Production Workflow.

This keeps the dropdowns clean while allowing the production system to become considerably more sophisticated underneath.
