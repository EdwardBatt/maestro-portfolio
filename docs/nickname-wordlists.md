# Resource nickname word lists — APPROVED (Edward, 2026-08-12)

Feeds the auto-generated resource **nickname** (ADR-0011): `<Adjective> <Noun>`, chosen at random,
**unique per tenant**, editable, with a 🎲 reroll. **Fun for all.** Nicknames are **internal-only** —
clients never see them. The bulk of the team is **Egyptian / Iraqi**, so the pools lean into shared,
affectionate MENA food & nature references plus creative-agency terms. The person's real name is always
shown beside the nickname, so recognition never suffers.

> **Status.** Edward signed off on this English-only list on 2026-08-12; it ships as-is. Because every
> nickname is **editable** in the UI (with a 🎲 reroll), anything that lands wrong on a given person is a
> one-click fix. **Future enhancement:** a native Egyptian/Iraqi Arabic speaker can green-light the
> Arabic-adjective expansion below (connotation, gender handling, cross-language reading) when we choose
> to add it — that pass is deferred, not blocking.

## Deliberately excluded (English-reading / policy traps)

- **Ful** (فول, Egyptian fava beans) — reads as "fool" in English. Skipped.
- Anything alcoholic or pork-related, religious, political, or regionally sensitive — out by policy.
