# Maestro ADR Log

Architecture Decision Records are the **living decision system** for Maestro. The design doc
is frozen at v15 (ADR-0001); every subsequent decision — Open Decision resolutions (design doc
§11), stack changes, schema-shape choices, rule changes — lands here as a numbered ADR.

Process: copy `0000-adr-template.md` → next number → write Context / Decision / Consequences →
status `proposed` → Edward accepts → update this index, the OD Gate table in `docs/TASKS.md`,
and any affected ⚠️ tasks. Accepted ADRs are immutable; to change course, write a new ADR that
supersedes the old one.
