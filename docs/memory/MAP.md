## The shape of the codebase

- `src/app/` — the shell. `router.tsx` is the whole route table; `permissions.tsx` is the RBAC core.
- `src/features/<name>/` — 20 deletable feature folders, each owning `api/`, `components/`, `hooks/`,
  `lib/`, `types.ts`. A feature never imports another feature's internals (34 edges currently break
  this — see [STATE.md](STATE.md)).
- `src/lib/` — unit-tested engines: capacity, bookings, campaigns, brief, review, search, assets,
  people — plus `i18n.ts`, `supabase.ts`, `env.ts`. Timezone maths lives *inside* the capacity and
  bookings engines; there is no `lib/tz`.
- `supabase/migrations/` — 170 files, forward-only. `supabase/tests/` — 92 pgTAP suites.
- `supabase/functions/` — Deno Edge Functions: `booking-transition`, `deliverable-transition`,
  `subtask-schedule`, `invite-user`, `update-user`, `list-user-status`, `notify-email`,
  `review-media`, `asset-url`, `chat`, `archive-sweep`, and the model-facing five —
  `ingest-brief`, `generate-brief`, `generate-deliverables`, `propose-concepts`,
  `read-brief-receipt`. Sixteen in all. Service-role usage lives here and nowhere else.
